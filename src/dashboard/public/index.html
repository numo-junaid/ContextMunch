01

AST Tree Decomposition

Babel/SWC parser parses raw JS/TS/JSX into a standard ECMAScript AST. It maps type annotations, JSDoc nodes, and structural layout blocks to memory nodes.

parseCode(rawCode, { plugins: ['typescript', 'jsx'] })
02

Semantic Context Compression

Compiler passes unwrap TypeScript assertions, delete type aliases, strip noise console logs, and collapse heavy nested JSX components into structural markdown signatures.

transformAST(ast, { stripTypes: true, abstractJSX: 'compact' })
03

SQLite Signature Deduplication

Every codebase file gets a SHA-256 fingerprint cached in Node 24 native SQLite. If the code AST hasn't changed, cached minification returns in sub-millisecond time.

cache.get(sha256Signature) // 0.3ms hit
